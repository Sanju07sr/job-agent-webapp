2 Customize Your Profile

Edit job_scanner.py and update these sections:

CANDIDATE_PROFILE = """
Name: [Your Name]
Experience: [e.g., 4 years in Python Development]
Skills: [e.g., Django, Flask, AWS, PostgreSQL]
Visa: [e.g., Stamp 4 (Ireland) - eligible to work full-time]
Location: [e.g., Dublin/Ireland (open to hybrid/remote)]
Certifications: [e.g., AWS Certified Developer]
Domain: [e.g., FinTech, E-commerce]
"""
TITLE_MUST_CONTAIN = [
    'python', 'django', 'backend', 'software engineer',
    'full stack', 'api developer', 'flask'
]
search_queries = [
    'Python Developer Ireland',
    'Backend Engineer Ireland',
    'Django Developer Ireland',
]

3 Set Up Secrets

Go to Settings → Secrets and variables → Actions in your forked repo and add:

  • SENDER_EMAIL: Your Gmail address (e.g., yourname@gmail.com)
  • SENDER_PASSWORD: Gmail App Password (Generate here)
  • RECIPIENT_EMAIL: Email where you want job alerts sent
  • OPENAI_API_KEY: Your OpenAI API key (Get key)
  • MIN_MATCH_PCT: Minimum match % to trigger alert (default: 50)

4 Enable GitHub Actions

Go to the Actions tab in your forked repo and click "I understand my workflows, go ahead and enable them"

5 Test Your Agent

Go to Actions → LinkedIn Job Scanner - 24/7 Agent → Run workflow to trigger a manual test run.

Check your email inbox (and spam folder) for job alerts!

⚙️ Customization Options

Edit .github/workflows/scan.yml to change the schedule:

schedule:
  - cron: '*/30 * * * *' # Every 30 minutes (default)
  # OR
  - cron: '0 * * * *' # Every hour
  # OR
  - cron: '0 */2 * * *' # Every 2 hours

📊 Monitor Your Agent

Check the Actions tab anytime to see:

  • ✅ Which jobs were found and scored
  • 📩 How many email alerts were sent
  • 🚫 Which jobs were filtered out (irrelevant titles)
  • ⏱️ Run history and success rate

🎯 Tips for Best Results

  • Be specific with job titles: Add exact titles you're targeting to reduce false positives
  • Update your profile regularly: Keep CANDIDATE_PROFILE in sync with your latest skills
  • Adjust match threshold: Start with 50%, increase to 70% if you get too many alerts
  • Check spam folder: First few emails might land in spam — mark as "Not Spam"
  • Monitor LinkedIn blocks: If you see 429 errors, the script auto-retries with delays

🆘 Need Help?

Common issues and solutions:

  • No emails received? Check GitHub Actions logs for errors, verify secrets are set correctly
  • Too many irrelevant jobs? Make TITLE_MUST_CONTAIN more specific
  • OpenAI rate limits? Script falls back to keyword scoring automatically
  • Gmail authentication failed? Regenerate App Password and update secret
